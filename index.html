PANEL PRIVADO · GOOGLE

Mis cuatro cuentas

Consulta el espacio libre de Google mediante la API oficial de Drive. No guardamos contraseñas ni enviamos datos a ningún servidor propio.

Debes abrir esta página desde una dirección HTTPS autorizada en tu proyecto de Google Cloud. Un archivo local file:// no permite iniciar sesión con Google.

Mis cuatro direcciones

Se guardan solo en este navegador, no en el repositorio público de GitHub.

Configuración inicial

  1. Publica los archivos de esta carpeta en un repositorio público de GitHub y activa Pages desde la rama main y carpeta /(root).
  2. En Google Cloud Console, crea un proyecto y configura la pantalla de consentimiento OAuth (tipo externo).
  3. Añade tus cuatro direcciones como usuarios de prueba si la app está en modo de pruebas.
  4. Activa Google Drive API.
  5. Crea un ID de cliente OAuth de tipo Aplicación web y añade solo el origen de tu web en Orígenes de JavaScript autorizados, por ejemplo https://usuario.github.io (sin ruta ni barra final).
  6. Copia el ID de cliente en el campo superior. Pulsa «Conectar» en cada cuenta y selecciona la dirección correspondiente.

La configuración de Google Cloud puede ser técnica. No publiques secretos de cliente: esta aplicación solo utiliza el ID de cliente público. El acceso solicitado es de solo lectura de metadatos de Drive. La pantalla de consentimiento puede requerir configuración de usuarios de prueba y, si Google cambia sus políticas, una verificación adicional.

Resumen

Conecta las cuentas para consultar el espacio.

Los tokens de acceso se conservan únicamente en memoria mientras esta pestaña permanezca abierta. El ID de cliente se guarda en este navegador. La cuota mostrada proviene de drive.about.get(fields=storageQuota); el valor puede no coincidir temporalmente con Google One, especialmente tras vaciar Papelera. Si una cuenta tiene almacenamiento ilimitado, Google puede no devolver un límite.
